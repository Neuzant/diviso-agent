# Code of Conduct

Diviso follows the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, no harassment or discrimination.
Maintainers may remove comments, commits and contributions that violate
this code, and may ban repeat offenders. Report problems to the maintainers
via a private GitHub report on the repository.
